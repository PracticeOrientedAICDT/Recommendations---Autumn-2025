This folder contains the code needed to run the experimental study on a webapp 

I have transfered this code for my personal repository since I did not want to use my university email for deployment. This is why, there are no previous commits relating to this application. 

The app uses React for front end. There initially was a backend as well; however, because we had problems with the hosted database not being persistent we switched to another method of saving the data, which was using an emailing service to email the participant data directly to a gmail account.

Some bits of code for database still remain in the codebase; however they are deprecated. 

To run this you need o install requirements.txt and start the servers or just find our application here (currently hosted using Vercel): https://movie-recs-navy.vercel.app
