# Movie Recommendation System using ChatGPT API

This system uses OpenAI's ChatGPT API to generate exactly 10 movie recommendations based on user prompts.

## Setup

1. Install dependencies:
```bash
pip install -r requirements.txt
```

2. Create a `.env` file with your OpenAI API key:
```bash
cp .env.example .env
```

3. Edit `.env` and add your OpenAI API key:
```
OPENAI_API_KEY=sk-your-actual-api-key-here
```
