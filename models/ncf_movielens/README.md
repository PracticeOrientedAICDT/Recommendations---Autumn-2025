# NCF (Neural Collaborative Filtering)

**How it works:**
NCF uses a neural network to learn the interaction function between users and items. Instead of just matrix factorization, it uses deep learning to capture complex, non-linear patterns in user-item interactions.

**Key features:**
- Learns non-linear user-item relationships
- Combines matrix factorization with neural networks
- Can model complex preference patterns
- Uses TensorFlow/Keras

**Training:** Neural network learns embeddings and interaction patterns through backpropagation
**Inference:** Forward pass through network to get prediction scores for user-item pairs
